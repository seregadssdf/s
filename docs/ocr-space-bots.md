# OCR.Space для ботов

`BotAutoCapcha` включён при создании бота, `BotCaptchaSave` выключен по
умолчанию (его можно включить вручную). Обычный игрокский `AutoCapcha` не изменён.
Боты больше не используют локальную нейросеть или Zenith Cloud для капчи.

## Ключ

Основной способ: откройте настройки бота → `BotAutoCapcha` → `OCR.Space API key`
и вставьте ключ. Поле скрывает введённое значение. Значение сохраняется штатным
механизмом конфигурации бота в открытом виде: не публикуйте конфиги и не включайте
их в архивы. В исходниках значение по умолчанию пустое. Для каждого бота используется
его настройка; можно применять настройки через существующее управление ботами.

Ключ не включён в JAR или исходники. Можно использовать уже полученный ключ,
но раскрытый ключ рекомендуется заменить. Для запуска через Gradle:

1. Скопируйте ключ в буфер обмена, без текста письма.
2. Выполните в PowerShell из корня проекта:

```powershell
New-Item -ItemType Directory -Force "run\config" | Out-Null
$key = (Get-Clipboard -Raw).Trim()
if ($key -notmatch '^[A-Za-z0-9]{8,128}$') { throw "В буфере должен быть только ключ" }
[IO.File]::WriteAllText((Join-Path $PWD "run\config\ocr-space.key"), $key)
Remove-Variable key
Set-Clipboard -Value ""
.\gradlew.bat runClient
```

Если клиент запускается через лаунчер, файл `config/ocr-space.key` должен лежать
в **игровой папке этого профиля**, а не обязательно в `C:\zenith-source\run`.
Альтернатива: переменная окружения `OCR_SPACE_API_KEY` у процесса клиента; она
имеет приоритет над файлом, но настройка модуля имеет приоритет над обоими.
Файл исключён из Git и читается при каждом запросе, если поле модуля пустое.
Не отправляйте его вместе с архивами, логами или проектом.

## Поведение

Полная PNG-картинка отправляется по HTTPS на официальный API OCR.Space с
движком 2. Ключ передаётся заголовком, не URL. Запрос выполняется вне потока
пакетов, общий для ботов ограничитель допускает только один запрос одновременно.
Повторного запроса на ошибочный OCR автоматически нет, чтобы не расходовать
квоту трижды. Таймаут HTTP — 30 секунд, соединения — 10 секунд.

Только успешный JSON с одним результатом и текстом из ровно пяти ASCII-цифр
отправляется в чат. Ведущие нули сохраняются. Буквы, команды, несколько ответов
и цифры с внутренними пробелами не исправляются догадками и не отправляются.
Если модуль выключен, бот отключён или карта обновилась, старый ответ отбрасывается.
Неполная собранная стена не отправляется в OCR.

В журнале бота видны начало запроса, отправленный ответ или причина отказа.
«Ответ отправлен» не означает «капча принята». Существующее сохранение отдельной
попытки в `captcha/hard` оставлено; тяжёлый сбор стен, JSON и тайлов через
`BotCaptchaSave` автоматически не запускается.

OCR.Space — обычный OCR, точность на сложных капчах не гарантируется. Пятизначный
ответ может быть неверным. Бесплатный лимит по документации — 500 запросов в
день на IP; аккаунт также ограничен месячной квотой. Не обходите эти ограничения.

## Проверка

```powershell
.\gradlew.bat test build
```

Тест использует локальный HTTP-сервер с фиктивным ключом: проверяет формат запроса,
ведущие нули, отказ на небезопасный/неполный текст, ошибки JSON и HTTP 429.
Тест не расходует облачную квоту и не проверяет принятие ответа игровым сервером.

Документация API: https://ocr.space/ocrapi
