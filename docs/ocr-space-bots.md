# OCR.Space для ботов

Во вкладке **PvE** откройте модуль **BotCaptcha** и вставьте ключ в поле
**OCR.Space API key**. Включать сам BotCaptcha не требуется: он хранит общие
настройки. В меню ботов включите **BotAutoCapcha** — все боты используют этот ключ.
Поле ключа удалено из индивидуальных настроек ботов. Старые настройки ботов,
переменная окружения и файл `config/ocr-space.key` больше не используются.

Ключ сохраняется штатным механизмом конфигурации клиента в открытом виде,
хотя текстовое поле использует режим скрытого ввода. Не публикуйте конфиги и
не включайте их в архивы. В исходниках значение по умолчанию пустое.

`BotAutoCapcha` включён при создании бота, `BotCaptchaSave` выключен по умолчанию
(его можно включить вручную). Обычный игрокский `AutoCapcha` не изменён.
Боты не используют локальную нейросеть или Zenith Cloud для капчи.

Полная PNG отправляется по HTTPS в OCR.Space, движок 2. Запрос выполняется вне
потока пакетов; общий ограничитель допускает один запрос одновременно. Ключ
передаётся заголовком и не выводится в журнал. Таймаут HTTP — 30 секунд.

В BotCaptcha включено «Сравнить OCR 1 и 2»: одна картинка проверяется двумя
движками (два запроса, двойной расход квоты). Если оба вернули разные пятизначные
ответы, отправка отменяется. Если только один дал корректный формат, используется
он — это всё ещё не гарантия правильности. Выключите сравнение для одного запроса
движком 2. В журнале бота записывается ParsedText каждого движка: управляющие
символы удаляются, текст ограничен 160 символами, совпадение с ключом скрывается.
При ошибке второго запроса ответ не отправляется. Сравнение прекращается, если
капча стала неактуальной. Предобработка изображения не применяется без проверки
её пользы на реальных данных.

Только успешный JSON с одним результатом и ровно пятью ASCII-цифрами отправляется
в чат. Ведущие нули сохраняются. Буквы, команды, несколько ответов и внутренние
пробелы не исправляются догадками. Устаревший ответ при обновлении карты,
отключении бота или выключении AutoCapcha отбрасывается. Неполная стена не
отправляется в OCR. Автоматические повторные запросы не расходуют квоту.

«Ответ отправлен» не означает «капча принята». Пятизначный ответ может оказаться
неверным. Обычный OCR не гарантирует распознавание сложных капч. Существующее
сохранение отдельной попытки в `captcha/hard` оставлено, тяжёлый сбор через
`BotCaptchaSave` автоматически не запускается.

## Проверка

```powershell
.\gradlew.bat test build
```

Тест использует локальный HTTP-сервер и фиктивный ключ; проверяет запрос, ведущие
нули, небезопасный текст, ошибки JSON и HTTP 429. Не проверяет игровой сервер.

Документация API и бесплатные лимиты: https://ocr.space/ocrapi
